# AzVMRestrictions

## Purpose
Just a few little resources to help aggregate information that may be useful when navigating some of the Azure AKU restrictions announced in July 2026.

Very basic, but they've been helpful when helping customers understand how their current landscape may be impacted by the announcement, in addition to other changes in the platform that should be considered as part of any modernization or migration efforts.

https://learn.microsoft.com/en-us/azure/virtual-machines/migration/sizes/previous-gen-series-capacity-limitations
